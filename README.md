<div align="center"> <h1>Machine Learning: Basic Principles 🤖</h1> </div>

<br>
Este repositório é um guia prático e teórico sobre os algoritmos clássicos de <b>Machine Learning (ML)</b>. O objetivo é consolidar o entendimento sobre o funcionamento interno de cada modelo, desde os fundamentos lineares até algoritmos de aprendizado supervisionado mais complexos.

Um dos principais objetivos desse repositório é na implementação dos modelos de ML sem a utilização de bibliotecas padrões (como por exemplo: Scikit-learn). Programando do zero (from scratch).

## 📚 Conteúdo do Repositório

O projeto está dividido em módulos, cada um focado em uma família de algoritmos:

### 1. Modelos Lineares e Redes Neurais Iniciais
* **Perceptron:** O bloco de construção das redes neurais modernas.
* **Multilayer Perceptron (MLP):** Introdução ao Deep Learning e retropropagação (*backpropagation*).

### 2. Classificadores Estatísticos e de Margem
* **Support Vector Machine (SVM):** Maximização de margens e o uso de kernels para dados não lineares.

* **Naive Bayes:** Classificação probabilística baseada no Teorema de Bayes.

### 3. Árvores e Métodos de Conjunto (Ensemble)
* **Decision Tree (Árvore de Decisão):** Entropia, ganho de informação e particionamento de dados.

* **Random Forest (Floresta Aleatória):** O poder da combinação de múltiplas árvores (Bootstrap Aggregating) para reduzir o overfitting.
